📖 About

The Maldives Experimental Wave Forecast System (MEWFS) is a research and development initiative focused on providing wave forecast guidance for Maldivian atolls and reef systems.


The system has been developed to improve understanding of wave conditions within the Maldives and to support coastal research, marine planning, education and future operational forecast development.


MEWFS combines numerical wave modelling, automated forecast production, scientific visualization and web dissemination technologies to provide an accessible platform for wave forecast information.

⚙️ Model Information

The forecasting system is based on the SWAN (Simulating WAves Nearshore) spectral wave model. SWAN is a third-generation spectral wave model widely used for simulating wave transformation in coastal and nearshore environments.


The model solves the spectral action balance equation and simulates wave propagation and transformation processes throughout the computational domain.


Processes Represented

  • Wave propagation
  • Wave shoaling
  • Wave refraction
  • Wave diffraction (where applicable)
  • Bottom friction
  • Depth-induced wave breaking
  • Non-linear wave-wave interactions
  • Wave energy dissipation

Computational Mesh

The Maldives contains highly complex reef-fringed coastlines, narrow channels, lagoons and shallow reef platforms. To accurately represent these environments, MEWFS utilizes unstructured triangular computational meshes.


Computational meshes are generated using the pyTri framework, a Python-based mesh generation system developed to create bathymetry-dependent triangular meshes for coastal and marine modelling applications.


The mesh generation procedure automatically varies mesh density according to bathymetry and geographical complexity, providing greater detail around reefs, coastlines and areas of interest while maintaining computational efficiency offshore.


Bathymetry

The bathymetric dataset used for model setup and mesh generation is based on the high-resolution Maldives bathymetric compilation described by Rasheed et al. (2020).


Rasheed et al. (2020) – High Resolution Bathymetry for the Maldives


Forecast Variables

  • Significant Wave Height (Hs)
  • Peak Wave Period (Tp)
  • Wave Direction
  • Spectral Wave Parameters

🔄 Forecast Workflow

1. Domain Definition

Computational domains are defined for selected Maldivian atolls. Bathymetric information and coastline geometry are combined to prepare the model domain.

2. Mesh Generation

pyTri is used to generate an unstructured triangular computational mesh. Mesh density varies according to local bathymetry and coastal complexity.

3. Boundary Forcing

Wave boundary conditions are obtained from larger-scale wave forecast guidance products and supplied along the open boundaries of the domain.

4. Forecast Simulation

The SWAN wave model performs the forecast simulation using the prepared forcing conditions and computational mesh.

5. Automation

Forecast preparation, execution, monitoring, post-processing and publication are managed using the Raalhu modelling workflow.

6. Visualization

Model outputs are converted to VTK formats and visualized using PyVista.

📡 Data Sources and Current Limitations

Computational Infrastructure

The current implementation of MEWFS operates using two Acer Veriton E10 ETBox mini-computers.


While these systems provide sufficient capability for the generation of experimental forecast products, they do not provide the computing resources available to dedicated operational forecasting systems or high-performance computing environments.


Consequently, forecast products are generated using simplified model configurations and reduced computational complexity compared with what would be achievable using larger computational infrastructure.


Current Limitations

  • MEWFS remains under active development.
  • Forecast products are generated using limited computational resources.
  • Model resolutions are currently constrained by available hardware.
  • Not all local-scale lagoon, reef and shoreline processes may be fully resolved.
  • Forecast coverage remains limited to selected atolls.
  • Model configurations have been simplified to maintain practical run times.
  • Forecast products should be interpreted as experimental guidance products.

📊 Validation

The Maldives Experimental Wave Forecast System is currently in its research and development phase.


A formal operational verification and validation framework has not yet been established.


Forecast products have not yet undergone comprehensive evaluation against wave buoy measurements, operational monitoring systems, or long-term hindcast validation datasets.


Current assessment is based primarily on internal testing, visual inspection and qualitative evaluation of forecast behaviour.


Future development activities are expected to include:

  • Wave buoy validation.
  • Satellite comparison studies.
  • Forecast skill assessment.
  • Error and uncertainty statistics.
  • Operational verification procedures.
  • Long-term hindcast evaluation.

Until a comprehensive validation programme is completed, all forecast products should be regarded as experimental research products.

🤝 Funding

The Maldives Experimental Wave Forecast System (MEWFS) was developed through a Small Grant Research Project funded by Maldives University.


Funding support contributed towards the development of numerical modelling workflows, unstructured mesh generation methodologies, forecast automation systems, scientific visualization tools and public dissemination of forecast products through the MEWFS web platform.

⚠ Disclaimer

MEWFS is an experimental research product.


Forecast information is provided for educational, research and situational-awareness purposes only.


The system has not yet undergone comprehensive operational validation and forecast products may contain uncertainty and modelling errors.


Forecast products MUST NOT be used for navigation, emergency response, voyage planning or any safety-critical decision making.


Users should consult official marine forecasts issued by the Maldives Meteorological Service for operational guidance.
